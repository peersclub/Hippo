> **[#100](https://github.com/peersclub/Hippo/pull/100) stops the guessing.** Confidence was always emitted and always ignored. The threshold needed no tuning — fast paths return 0.92–0.97 and `rule_classify` fallbacks 0.6–0.8, so 0.85 sits in an empty gap, and **a Python test asserts the gap stays empty** so a future 0.87 branch fails loudly. Cheap intents NEVER clarify — being wrong about a research question costs a re-ask.
